# Example skins

Two complete skins used by the README and the format documentation:

| Folder | Background | Notes |
| --- | --- | --- |
| `lavender-dream` | `background.jpg` | still image |
| `winter-pines` | `background.mp4` | looping video, small enough for the repo |

Each folder is a normal skin: `skin.json`, its background and a `logo.svg`. To use one locally, copy
the folder into `~/.config/dsh/skins/` (or into a collection folder under it), then pick it in
**Settings → Skins**. The media is included for demonstration; replace it with your own before
redistributing a skin.
